UNDO-REDO TEXT EDITOR — LIGHT THEME WEB DEMO

Files:
- index.html: the complete browser demo
- .nojekyll: GitHub Pages helper

Publish/update on GitHub Pages:
1. Open your repository: https://github.com/iamdharamveer/Undo-Redo-Text-Editor
2. Open index.html, choose Edit (pencil), replace its contents with the updated index.html file, and commit.
   OR upload the updated index.html from the repository root and choose to replace the existing file.
3. Wait a minute, then refresh: https://iamdharamveer.github.io/Undo-Redo-Text-Editor/

The demo includes editing, undo, redo, clear, opening/saving .txt files, action history,
character/word/line counts, and Ctrl+Z / Ctrl+Y (also Ctrl+Shift+Z).
