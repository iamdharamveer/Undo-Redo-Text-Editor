# Undo-Redo Text Editor — Web Demo

This folder contains a browser-based demo of the C++/Qt Undo-Redo Text Editor project. It offers typing, undo, redo, clear, open/save `.txt`, and an editing-history panel.

## Publish on GitHub Pages
1. Upload `index.html` and `.nojekyll` to the **root** of the existing `Undo-Redo-Text-Editor` repository.
2. Commit the changes to `main`.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes and open: https://iamdharamveer.github.io/Undo-Redo-Text-Editor/

Note: this is a browser-based companion demo; it does not run the original C++/Qt desktop binary inside the browser. Keep the C++ source files in the repository too.
